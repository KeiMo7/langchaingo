# benchmark_out

Sample artifacts from the evaluation tool, generated by
`EVAL_WRITE_BENCHMARK_OUT=1 go test ./eval/ -run TestWriteBenchmarkOut`.
The run is fully offline: it scores a canned target (`demoSystem` in
`eval/benchmark_test.go`) over `eval/testdata/demo_samples.json`.

| File | What it is |
| --- | --- |
| `report_before_report.txt` | Human-readable report for prompt-v1. |
| `report_before_canonical.json` | Deterministic report for prompt-v1; the file to diff or use as a CI baseline. |
| `report_before_full.json` | Full report including volatile metadata (timestamps, durations, cache counters). |
| `report_after_*.{txt,json}` | The same three forms for prompt-v2. |
| `comparison.txt` / `comparison.json` | Deltas between the two runs, per category and per changed sample. |

## What the sample run shows

- **Seven samples, five categories, one deliberate upstream failure.**
  `bill-02` fails with `invalid_request`. It is recorded as a failure, is not
  retried (a permanent error), is excluded from metric means, and its metrics
  are `nil` (printed as `not_scored`) rather than zero.
- **Usage is only known for two samples.** Their token counts feed the means;
  the unknown ones are counted under `usage_unknown` and excluded, so the
  means are not diluted by zeros.
- **Retrieval is scored where reference materials exist.** `acct-01` retrieved
  one relevant and one irrelevant document (recall 1, precision 0.5);
  `acct-02` retrieved only an irrelevant one (recall 0); samples without a
  retriever report `unknown`, not zero.
- **The prompt change is visible.** `prompt-v2` makes `acct-01` answer with a
  sentence that drops every key point, so overall exact match and F1 fall from
  1.0000 to 0.8333, and the account category falls from 1.0000 to 0.5000. The
  comparison names the single changed sample.
- **The report is reproducible.** Timestamps and durations live in the
  top-level `meta` block, which is excluded from the canonical report; running
  the generator twice produces byte-identical canonical files.
